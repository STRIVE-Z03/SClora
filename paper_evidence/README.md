# Paper Evidence

## English

This folder contains partial running data and cleaned log summaries used to support the paper results.

The public package documents only the LASRC and SCALE-FG implementation paths. These files are provided for result tracing and sanity checking, not as executable experiment scripts. Local paths and machine-specific information have been removed or anonymized, and documentation paths use placeholders such as `xx/xx`.

## 中文

本文件夹包含用于支撑论文结果的部分运行数据和清理后的日志摘要。

公开代码包只说明 LASRC 和 SCALE-FG 两条实现路径。这些文件用于结果追踪和基本核验，不作为可执行实验脚本提供。涉及本地路径和机器环境的信息已删除或匿名化，文档中的路径统一使用 `xx/xx` 等占位形式。
